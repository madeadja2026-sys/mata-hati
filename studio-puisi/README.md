# Studio Puisi PWA

Aplikasi puisi berbahasa Indonesia, responsif untuk HP dan laptop.

## Fitur
- Pengaturan tema, tujuan, gaya, emosi, sudut pandang, struktur, panjang, dan penutup.
- Draf puisi yang bisa disunting langsung.
- Simpan koleksi di penyimpanan lokal browser.
- Salin, unduh TXT, cetak/PDF, ekspor dan pulihkan cadangan JSON.
- PWA dengan manifest, ikon, dan service worker untuk penggunaan offline setelah dibuka pertama kali.

## Instal di Android
1. Buka URL aplikasi melalui Google Chrome.
2. Ketuk menu ⋮ lalu pilih **Instal aplikasi** atau **Tambahkan ke layar utama**.
3. Buka ikon Studio Puisi dari layar utama.

## Catatan data
Karya disimpan di browser/perangkat yang digunakan, tidak tersinkron otomatis antarperangkat. Ekspor cadangan JSON secara berkala.
