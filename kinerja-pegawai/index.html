Catatan operasional

  • GitHub Pages hanya menghosting berkas statis; bukan database bersama atau server autentikasi.
  • Offline: aplikasi dan data lokal pada perangkat yang sama dapat dibuka tanpa internet setelah pertama kali dimuat.
  • Untuk multi-pengguna, login aman, audit perubahan, dan sinkronisasi lintas perangkat, diperlukan backend terproteksi yang belum terhubung pada versi ini.
